## 🎯 策略逻辑

### 核心思路

```
每根 5m K 线开盘时:
    ↓
1. 检查 4h/1h/15m 趋势（MA20 vs MA50）
2. 计算 5m RSI(14)
3. 如果多周期趋势一致 + RSI 超买/超卖 → 开仓
4. 持有 1 根 K 线（5 分钟）
5. 下一根 K 线收盘自动平仓
```

### 开仓条件

**做多 (UP)**:
- 4h 趋势：MA20 > MA50（或持平）
- 1h 趋势：MA20 > MA50（或持平）
- 15m 趋势：MA20 > MA50（或持平）
- RSI(14) < 30（超卖）

**做空 (DOWN)**:
- 4h 趋势：MA20 < MA50（或持平）
- 1h 趋势：MA20 < MA50（或持平）
- 15m 趋势：MA20 < MA50（或持平）
- RSI(14) > 80（超买）

## 🔧 参数配置

```yaml
strategy:
  name: "MTF-RSI"
  rsi_period: 14
  rsi_overbought: 80
  rsi_oversold: 30
  hold_period: 1  # 持有 K 线数
  
trend_filter:
  enabled: true
  mode: "all"  # all/major/1h/none
  ma_fast: 20
  ma_slow: 50
  
trading:
  symbol: "BTCUSDT"
  timeframe: "5m"
  target_win_rate: 0.60
  target_monthly_orders: 150
  
risk:
  max_position_size: 1000  # USDT
  max_daily_loss: 500  # USDT
  max_open_orders: 5
```

## 📊 策略评估

### 优势

- ✅ 逻辑简单清晰，易于理解和执行
- ✅ 多周期趋势过滤，减少假信号
- ✅ 胜率 57.44%，在业界属于优秀水平
- ✅ 订单充足（184 单/月），适合小资金快速周转

### 劣势

- ⚠️ 胜率 57.44% 未达到 60% 目标
- ⚠️ 持仓时间短（5 分钟），对执行速度要求高
- ⚠️ 无止盈止损，单笔亏损可能较大

### 改进方向

- 添加波动率过滤
- 添加成交量确认
- 优化 RSI 阈值
- 尝试不同持仓时间
- 多策略组合
